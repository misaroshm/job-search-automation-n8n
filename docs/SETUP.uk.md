# Як запустити (покроково)

Усе налаштування займає приблизно 40 хвилин. Найдовше йде на Google Cloud, решта швидко.

## 0. Що знадобиться

- **Docker Desktop**: https://www.docker.com/products/docker-desktop/ . Встанови, запусти і в налаштуваннях увімкни "Start Docker Desktop when you sign in", щоб після перезавантаження все піднімалось саме.
- Твій Telegram-бот (той самий Vacancy) і його токен.
- Таблиця "Трекер вакансій" (вже є).

## 1. Вимкни старі тригери в Apps Script

Інакше старий бот і новий надсилатимуть одне й те саме двічі.

1. У таблиці відкрий **Розширення → Apps Script**.
2. Ліворуч натисни іконку будильника (**Тригери**).
3. Видали всі тригери (три крапки → Видалити тригер): `pollTelegram`, `dailyCheck`, `scheduledVacancySearch`, `onLinkEdit`.

Сам код можна не чіпати: кольори і запис історії при ручних змінах у таблиці працюватимуть далі. Cloudflare (і Worker, і тунель) теж більше не потрібен.

## 2. Сервісний акаунт Google (щоб n8n міг читати й писати таблицю)

1. Відкрий https://console.cloud.google.com і створи новий проєкт, наприклад `job-tracker`.
2. **APIs & Services → Library**: знайди й увімкни (**Enable**) **Google Sheets API**, а потім **Google Drive API**.
3. **IAM & Admin → Service Accounts → Create service account**. Назва `job-tracker-n8n`, ролі можна не давати, натисни **Done**.
4. Відкрий створений акаунт → вкладка **Keys → Add key → Create new key → JSON**. Завантажиться файл.
5. Перейменуй його на `google-service-account.json` і поклади в папку `setup/` цього проєкту.
6. Скопіюй email сервісного акаунта (закінчується на `.iam.gserviceaccount.com`). Відкрий таблицю, натисни **Поділитися**, встав цей email, вибери **Редактор** і зніми галочку "Сповістити".

## 3. Ключ Gemini

Відкрий https://aistudio.google.com/apikey і натисни **Create API key**. Ключ безкоштовний.

## 4. Заповни .env

Скопіюй `.env.example` у `.env` (або просто запусти `./setup.sh`, він зробить це сам і зупиниться) і впиши:

```
TELEGRAM_BOT_TOKEN=токен від @BotFather
TELEGRAM_CHAT_ID=
SHEET_ID=id таблиці з посилання, між /d/ і /edit
GEMINI_API_KEY=ключ з AI Studio
```

`TELEGRAM_CHAT_ID` поки лиши порожнім, бот сам скаже його на кроці 6.

## 5. Запуск

**Mac:** відкрий Термінал у папці проєкту і виконай:
```bash
chmod +x setup.sh
./setup.sh
```

**Windows:** відкрий PowerShell у папці проєкту:
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

Перший раз Docker завантажує образи, це кілька хвилин.

## 6. Перший вхід

1. Відкрий http://localhost:5678 і створи акаунт n8n. Це локальний акаунт, він живе тільки на твоєму комп'ютері.
2. Напиши боту `/start`. Він відповість **твоїм chat id**.
3. Впиши цей номер у `.env` у `TELEGRAM_CHAT_ID=` і перезапусти n8n:
   ```bash
   docker compose up -d --force-recreate n8n
   ```
4. Ще раз напиши `/start`. Тепер з'являться кнопки внизу екрана.
5. Натисни **🔎 Шукати нові**. За хвилину-дві прийдуть картки вакансій.

## Як цим користуватись

- **Кнопки внизу:** пошук, нерозібрані, активні, сьогодні, статистика, аналіз відмов.
- **Посилання на вакансію** просто кидай боту, він сам додасть її в таблицю.
- **Відмова:** постав етап "Відмова", встав текст листа в "Нотатки". Увечері (або одразу через `/insights`) AI розбере його, допише в таблицю колонки "AI: …" і надішле тобі розбір.
- **За розкладом:** пошук о 9:00 і 19:00, зведення о 9:05, розбір відмов о 20:00, тижневі висновки в понеділок о 10:00.

Усе працює, поки ноутбук увімкнений і Docker запущений. Бот сам забирає повідомлення з Telegram кожні 5 секунд, тому після сну ноутбука просто продовжує працювати, нічого перезапускати не треба. Якщо о 9:00 ноутбук спав, пошук і зведення запустяться, щойно він прокинеться.

## Якщо щось не так

- **Помилки** приходять у Telegram самі, з посиланням на виконання в n8n.
- **Бот мовчить:** перевір, що Docker запущений (кит у рядку меню), і виконай `docker compose ps`. Якщо контейнер не `Up`, то `docker compose up -d`. Логи: `docker compose logs --tail 40 n8n`.
- **Історія всіх запусків:** http://localhost:5678 → Executions.
- **Змінити налаштування** (поріг балів, кількість карток тощо): правиш `.env`, потім `docker compose up -d --force-recreate n8n`.
- **Оновити workflow після змін у коді:** `npm test && npm run build`, потім знову `./setup.sh`.

## Оновлення до нової версії

1. Заміни файли проєкту новими з архіву, але **збережи** свій `.env` і `setup/google-service-account.json`.
2. У Терміналі в папці проєкту: `./setup.sh`. Він перезавантажить workflow і прибере зайві старі контейнери.
